# Changelog

## 1.0.0 - 2026-06-13

- Complete the original K-LIB Forge local-first roadmap.
- Add local vector, Chroma, Qdrant, and hybrid retrieval adapters.
- Add knowledge suggestions, correction review, trust scanning, and richer PDF metadata.
- Add full package editors, import/export, model profiles, run history, and prompt inspection.
- Add multi-model Eval Arena, Python SDK, and MCP stdio server.
- Add primary-literature biology benchmarks and resilient NVIDIA API execution.
- Add locked Python dependencies, CI, signed Windows release support, checksums, and SBOMs.
- Promote the desktop, API, CLI, SDK, and package format to public 1.0 release status.

## 0.1.1

- Package the FastAPI backend as a Windows sidecar.
- Start and stop the backend automatically from Tauri.
- Discover the managed API on a dynamic localhost port.
- Add an idempotent first-run Arabic translation demo installer.
- Add desktop `.klib` export and an NSIS Windows installer.

## 0.1.0

- Initial `.klib` core, CLI, API, desktop shell, eval, and Knowledge Diff release.
