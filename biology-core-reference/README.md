# Core Biology Reference - K-LIB library

A deep, multi-document biology library for grounded question answering and A/B testing.

## Coverage (10 source documents)

1. Cell biology and organelles
2. Membrane transport
3. Bioenergetics and cellular respiration
4. The central dogma and the genetic code
5. Classical and molecular genetics
6. Enzymes and enzyme kinetics
7. The cell cycle, mitosis, and meiosis
8. Photosynthesis
9. Cell signaling and neurophysiology
10. A clearly labeled fictional internal hypoxia-reporter assay

## Authored inputs

- manifest.json, rules.md (6 rules), glossary.json (30 terms), examples.jsonl
- sources/ - nine public-reference documents plus one internal-protocol demo
- evals/ - 25 cases: 20 public biology, 4 private-protocol, and 1 control
- corrections.jsonl - empty, ready for corrections-as-regression-evals

## Generated by your compiler

build/, chunks/, indexes/, runs/ are produced when you build and run the library.

## Eval design

Checks target precise, easily-confused facts where smaller open-weight models tend to
fail without grounding: exact stoichiometry (glycolysis 2/2/2; Krebs per turn; Na/K pump
3-out/2-in), the genetic code (64 codons; start AUG/Met; stops UAA/UAG/UGA), ordered
processes (mitosis phases), and exact definitions (Km at half Vmax). The control
(12 x 12) should score the same with and without the library, confirming the library is
not a general boost.

## Schema notes

manifest.json, rules.md, and evals/*.json mirror an existing built library. glossary.json
and examples.jsonl use a conventional {term, definition} / {input, output} shape; adjust
keys if your compiler expects different ones.

## A/B expectation

This is real biology, so a capable model already knows the broad strokes and the baseline
will not be near zero on the first nine documents. The fictional Aster-9 protocol provides
the private-knowledge case: an ungrounded model should admit that it cannot know the
internal values, while the K-LIB condition should recover them exactly with a citation.

The Aster-9 document is explicitly fictional and is not a real laboratory or clinical
protocol.
